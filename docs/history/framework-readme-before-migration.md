# 炮姐 Mod：实现框架

这是一个可编译、可验证的 Java 核心框架，用于承接后续 Minecraft 模组开发。它还不是可以直接放进 `mods` 文件夹的模组。

当前工作关注实现逻辑。最新用户要求是将角色与能力、世界内容分开推进，并面向 Minecraft Java 版1.20及以上。具体游戏小版本、加载器、角色形式、成长曲线和技能表现仍待选择。

## 已实现

| 部分 | 当前能力 |
| --- | --- |
| 内容定义 | 独立的能力与可选角色资料定义，稳定 ID，不包含具体动漫角色 |
| 能力依赖 | 前置能力和阶数校验，拒绝缺失引用、重复 ID 与循环前置 |
| 玩家状态 | 选择槽、能力阶数、通用资源、冷却截止时间、不可变数据快照 |
| 学习流程 | 前置检查、可替换规则、资源检查、扣费和解锁 |
| 释放流程 | 学习状态、冷却、规则、资源检查，准备效果后再提交状态 |
| 成长策略 | 接收由服务端确认的事件，由外部策略决定资源奖励 |
| 外部接口 | 存档、同步、外观、时钟、技能行为的适配契约 |

上述资料对象可由未来的 JSON、数据包或代码加载器构建；目前尚未实现文件格式解析。

## 本地验证

需要 JDK 9 或更高版本以使用 `javac --release`；本次使用 JDK 17。Java 8 字节码仅用于保持核心代码的可移植性，不代表已经选择 Minecraft 1.12.2。

在此目录运行：

```powershell
.\verify.ps1
```

脚本不需要联网或第三方依赖。它会编译核心和场景验证程序，验证关键状态约束，并在 `.build/<本次构建 ID>/railgun-core.jar` 生成核心库。每次使用独立目录，避免旧编译文件影响结果。

场景验证使用 `demo:*` 合成资料，不是角色、资源名称或技能数值的设计提案。验证涵盖学习前置、角色策略、失败时不扣费、效果请求、冷却边界、快照恢复和数值溢出。

## 使用边界

`AbilityEngine` 只能由游戏服务端主线程调用。请求的玩家身份、目标、距离、视线、输入频率和事件归属必须由 Minecraft 适配层确认。

`Outcome.effects` 是待游戏层执行的效果请求，当前不会造成 Minecraft 伤害或产生粒子。核心状态提交与实际世界修改也尚未组成跨系统事务；适配层需要保证只消费一次，并处理执行失败。

存档接口尚未连接磁盘或 Minecraft 玩家数据；本次验证的是快照重建。外观、网络、持续施法和游戏内界面也尚未实现。

当前源码为本次新建，没有复制原模组的源码、贴图、模型或音频。

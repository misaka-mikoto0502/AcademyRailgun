记录日期：2026-10-21。目标是建立可核对、可继续补充的知识基础。最新要求为Minecraft Java版至少1.20，角色与世界内容分开推进；当前建立1.21.1 NeoForge技术小样，正式平台与玩法形式仍待选定。

## 记录约定

“官方事实”指对应版本文档或发行说明明确给出的内容；“源码观察”仅覆盖标出的文件和方法；“项目推导”是可讨论的工程判断。文档里的后续步骤不锁定玩法。

未来改变目标版本时，重新核对游戏版本、加载器、Java、构建插件、映射方式和依赖模组这组组合，不能只修改版本号或更换 imports。`latest`、`current` 和 Git 分支都会变化；源码案例已额外固定到提交。

本轮最重要的认识是：版本兼容、玩家数据生命周期、服务端结算、客户端表现和内容配置需要分别验证。独立 Java 原型可以帮助验证规则，但不能证明 Forge 接入、联机或存档正确。

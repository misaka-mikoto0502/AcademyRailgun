# 三版角色与科技成长方案对比

日期：2026-10-22。三位子代理分别形成完整方案，主代理统一边界并交叉检查。三版都是候选设计，不是同时开发的三个项目；材料、配方、技能、槽位、CD、概率和物品规则中的新细节均可继续调整，尚未实玩验证。

## 先看哪一版

| 版本 | 核心乐趣 | 适合的取向 | 完整方案 |
| --- | --- | --- | --- |
| A 原版生存科技线 | 采集、回基地研究、改装，再用能力改善下一轮生存 | 进程清楚、材料体系相对收敛 | [方案A](plan-a-survival.md) |
| B 探索发现研究线 | 选研究对象、拿来源线索、定向采样，再解析能力 | 自由探索、农业养殖、研究目标感 | [方案B](plan-b-discovery.md) |
| C 操作连携挑战线 | 配好主副后切换接招，用能力处理战斗和生产问题 | 操作爽快、技能组合、较早体验Lv5 | [方案C](plan-c-combos.md) |

三版都覆盖科技、角色、装置、连携、材料和多人规则。区别是整个发展过程的重心，不是分别只做一个子系统。

## 共同保留的设计

- 铁阶段入门，主世界进阶Lv4，跨维度资源或挑战Lv5，终局研究与突破Lv6。
- 玩家操控资格全局共用，科技研究与突破材料推动资格；每名角色仍需特定解锁条件，角色与技能分别培养。
- 同一台装置持续改进；一主一副、有限技能携带、主深副浅。基地固定科技设施才能改配置，外出切换只换操作侧。
- 切换CD独立，切换后立即用可用技能；两侧技能CD各自计时，效果有限残留，连携随培养发展。
- 个人培养独立；战斗、探索、农业、养殖有各自用途。材料可定向追求，也可随机发现；抽卡延后。
- 每次阶段研究同时推进个人资格和自己的装置承载，减少重复交三套突破材料。具体角色再交自己的样本或完成条件。
- 基础体验不依赖独立世界内容模块、专属敌人、新维度或大型外部Mod。首版建议先贯通铁阶段至Lv4，完整四阶段仍保留在规划中。

## 关键差异

下表中的数字全部为各版调参起点，不代表已确认平衡。

| 比较项 | A 原版生存科技线 | B 探索发现研究线 | C 操作连携挑战线 |
| --- | --- | --- | --- |
| Lv4入口 | 红石、钻石与主世界活动记录 | 主世界特性样本与阶段研究 | 深层采矿、探索样本和解析 |
| Lv5开放时机 | 下界材料加末地考察后 | 下界、末地各自现场记录后 | 下界研究即可开放，末地作为后续扩展 |
| Lv6目标 | 三维度定向研究与极限解析 | 三维度观测设施与联合研究 | 末地探索、稀有资源和协同校准 |
| 长期目标呈现 | 阶段配方、角色特性样本 | 研究手册、来源线索、课题 | 可选实验与技能专精、连携 |
| 主副主动技能 | 主4、副2，另各选1被动 | 主3、副2 | 主3加主修被动，副2普通技能 |
| 切换CD | 6秒，改装最低3秒 | 6秒，改装后4秒 | 6秒，改装后4秒 |
| 独立效果残留 | 2秒起步，成长至4秒 | 2秒起步，成长至4秒 | 2秒起步，成长至4秒 |
| 随机与定向获得 | 有效批次2%样本，40点研究兑换 | 有效采样2%样本，40枚分类残片兑换 | 普通怪1%直接掉落，加主动搜刮4%独立机会；30点分类解析兑换 |
| 装置携带 | 背包固定槽 | 独立装备位 | 腕部入口，共用技能键位 |
| 死亡处理提案 | 回基地付普通修复材料取回，原件失效 | 装置随身保留，材料按世界规则处理 | 按世界规则掉落，付材料恢复固定成长，原件失效 |

A的“有效批次”、B的“有效采样”和C的“有效事件”单位不同，不能直接把兑换数字比较成谁快谁慢。非战斗事件、怪物击杀和批次大小需分别校准。C两次随机机会若独立，则合计至少出一次的概率为1－0.99×0.96，即4.96%，另有稳定解析进度；定向兑换不因随机出货清零。

三版都允许普通怪物带来惊喜，但没有将所有高档材料都塞入僵尸掉落表。来源、当前开放档位与装置鉴别能力在定稿时需形成完整掉落表。

## 主代理建议

我更倾向以C作为主案候选。它让Lv5能力参与后续末地挑战，角色获得后有充分的使用场景；主3副2并共享按键，也比较贴近快捷切换的操作目标。

可以吸收B的研究手册与定向采样流程，让玩家既能追求喜欢的角色，也能选择探索、农养和战斗路线。A对活动批次、研究点和修复恢复的具体说明，可以作为调整材料产量与物品规则的参考。

这只是推荐组合方向，没有把三套残片、研究点和解析进度全部叠加。定稿时只保留一套统一材料与研究积累规则；同样只选择一套装置死亡规则和一套基地登记规则。

## 仍需取舍的几项

1. Lv5更早在下界研究后开放，还是完成末地调查后开放。前者让能力参与末地推进，后者把更多探索放在解锁之前。
2. 主要发展乐趣更偏配方与原版资源、课题采样，还是技能实验与操作。三者可以组合，但应有一个主循环。
3. 装置死亡保留、基地恢复或正常掉落加恢复，选择哪一套。
4. 基地固定设施如何防止变成随放随用的便携配置台；允许多个完整基地，但不能让外出切换变成随时改主副。
5. 首版角色与通用分支的实际数量。三版给出的两份档案或四分支均为候选规模，不能据此承诺全员角色。
6. 随机词条是否在主线稳定后加入。三版均建议以稳定科技支持基础承载，再用词条优化体验。

## 后续使用

先选更喜欢的主循环和Lv5开放节奏，再合并材料、装置与连携规则。之后才能据完整设计确定实施范围；本次未写主题玩法代码，也未重新进行游戏或构建测试。

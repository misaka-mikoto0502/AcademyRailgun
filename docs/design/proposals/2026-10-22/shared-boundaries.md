# 三版方案的共同边界与原版依据

日期：2026-10-22。本文用于审核三版候选设计。材料名称、设施、技能与数值中超出原版的部分均是自建提案；正式平台尚未锁定，技术基线暂按已准备的Minecraft Java 1.21.1理解。

## 三版必须共同保留

1. 铁阶段用基础装置和通用能力辅助生存；主世界进阶开放Lv4；跨维度资源或挑战开放Lv5；终局专门研究与突破开放Lv6。
2. 个人操控资格全局共用，主要靠科技研究与突破材料；角色另外满足特定解锁材料或条件，各角色与技能单独培养。使用经验主要作用于角色技能。
3. 多角色可培养，当前一主一副、技能携带有限、主深副浅。只能在基地固定科技设施配置，外出切换不能交换主副身份。
4. 切换有独立CD，切换后立即使用当前可用技能，两角色技能CD持续独立计时。效果有限残留，留出技能、角色、等级与连携差异。
5. 个人培养归玩家，玩家彼此独立。统一随身装置持续改进，有承载与性能成长；随机词条只作为候选优化，抽卡延后且不是角色获取主来源。
6. 保留通用能力在战斗、探索、农业、养殖等领域的作用，以及定向寻找和随机发现并存的材料体验。搜刮装置等级可影响物品池与概率，具体交互由各版提案补全。
7. 角色基础体验不依赖独立世界内容模块、新维度、专属敌人或第三方大型Mod。研究、个人认证和装置升级尽量共享同阶段投入，减少重复刷取。
8. 这次只做方案文档。用户授权代理发挥未定细节，不等于选择某版，更不等于已启动代码实现。

原版允许玩家选择不同探索与资源获取路径。将某件物品、一次研究或某个挑战指定为本Mod的突破门槛，是方案自己新增的设计，不是原版强制科技树。任何“搜刮样本”“研究点”“装置承载”“角色资格”均属于本项目新增机制。

Lv6是本项目终局游戏档位。方案中出现高档解析态、组合态等提议时，不能写成原作角色已经具备该等级的事实。不同角色的游戏技能与用途也需在定稿时单独审核。

## 审核时检查什么

- 每版是否明确给出四阶段玩法、个人突破、角色解锁、装置改装和技能培养的分工。
- 原版来源与新增材料是否区分；原版探索事实有无颠倒。
- 副修是否仍有限制，切换是否被误写为双主修或重置冷却。
- 获取材料是否既能主动追求又有惊喜，是否存在明确可达的定向路径。
- 概率、兑换阈值、CD、槽位和残留时长是否都标为待实玩调参的初值。
- 设施移动、物品丢失、多人归属、重复领取与成长继承是否有可讨论的具体规则。
- 首版范围是否可以收缩验证，是否保持非战斗用途。

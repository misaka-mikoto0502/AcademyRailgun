# 角色与能力设计讨论稿

更新日期：2026-10-22。状态：设计讨论中，尚未定稿，也未开始主题玩法实现。

本文记录本轮对话确认的方向与尚未解决的问题。项目总边界见 [project-boundaries.md](project-boundaries.md)，2026-10-21 的讨论顺序与工程检查结果见 [历史检查点](../checkpoints/2026-10-21.md)；该快照保留原样，本稿继续追加后续设计。这里的“角色”“能力者”“主修”“副修”“变身器”均为讨论用语，最终名称与表现尚未确定。

## 工作方式与体验目标

- 采用问答方式逐步确定宏观设计与细节；允许回看和修改先前选择。
- 先完成设计讨论，等用户明确确认方案后再进入主题玩法实现。整理文档和维护现有验证工程不代表启动玩法开发。
- 核心目标是让玩家玩得爽、长期有内容可玩，并保留自由度、创造性与连携空间。
- 用有限携带形成搭配选择；避免增加缺乏玩法价值的限制。
- 角色部分先具备独立体验，以原版活动作为发展基础；与世界内容部分的关系继续遵守项目总边界。

## 已确认：培养范围与当前搭配

| 项目 | 当前确认的方向 | 尚待细化 |
| --- | --- | --- |
| 培养名单 | 可以逐渐培养多名角色 | 首版名单、总量与解锁次序 |
| 当前携带 | 一台随身装置配置两名不同能力者，以一主一副组织；外出快捷切换操作栏，主副关系不变 | 是否允许只带一个、装置携带或装备位置、具体按键 |
| 进度保留 | 培养成果归玩家本人，各玩家独立；换搭配或更换装置后保留 | 死亡、交易、借用和多人边界的具体规则 |
| 技能携带 | 每名能力者可携带的技能数量设上限 | 主副各自数量、主动与被动是否分别计数 |
| 主修深度 | 能够深入发展本体系的特色与核心能力 | 完整技能范围、成长上限与专精 |
| 副修深度 | 只能学习其他体系的有限部分；掌握与体系内契合程度低于本体 | 跨系可学清单、效果差异与组合规则 |

携带数量与可培养角色数量分开处理。用户保留了扮演原作角色本人、以自己的身份获得能力这两种方向；它们如何共存、是否需要独立模式，以及外观和能力是否绑定，尚未确定。

## 已确认：能力深度与多用途

能力需要具备足够的体系内发展空间，并通过有限搭配产生创造性和连携。能力应同时服务于战斗之外的活动，例如探索、生存、建造及环境交互；具体技能用途逐项设计。

用户认可三个重点：深入开发同一能力体系；成长持续增加行动选择；能力之间及其与环境之间能够相互作用。

“电磁方向可以研究远程攻击、感知、牵引、干扰”是用户认可的设计思路，尚不是已确定的技能清单。所有具体作用对象、操作规则、表现和数值均未锁定。

## 已确认：角色与技能成长

- 角色需要培养，技能也需要升级，两者如何关联尚待确定。
- 成长结合游戏内矿物或其他资源，并需要时间投入。
- 部分技能还需要频繁使用、战斗或击败怪物来提升；并未要求所有技能都同时满足全部条件。
- 长期发展应与原版玩法相结合。
- 用户提出“核心能力、关键能力、普通能力、特殊能力”等分类方向，用于讨论角色特色与跨系学习范围。正式分类、互斥关系、升级条件与权限尚未确定。

时间如何体现为探索、练习、研究、制作耗时或其他过程尚未选择；没有确认强制等待计时。成长曲线、资源条、等级与熟练度上限也尚未确定。

## 已确认方向：角色档位与全局操控上限

Lv4、Lv5、Lv6等表示角色档位，不直接等同于每名角色当前的培养程度。用户提出Lv4以下可采用通用能力与多个分支，支持战斗、探索、农业、养殖等不同路线；较高档位对应特定角色。具体分档边界、角色分布和通用能力与具名角色的关系尚未确定。

玩家能操控的档位需要在游戏过程中提升。用户选择倾向于全局共用：突破到可操控Lv4后，所有已解锁的Lv4角色获得相应操控资格；每名角色和技能仍然单独培养。

全局操控资格与具体角色解锁分别处理。操控上限提高后，每名角色仍受自身特定材料或其他解锁条件约束，不会自动解锁该档位所有角色。装置的具体承载条件也仍需满足，详细关系与数值待定。

| 层次 | 当前作用 | 待定内容 |
| --- | --- | --- |
| 角色档位 | 表示角色所属能力档位 | 分档、角色名单、通用分支与具名角色对应 |
| 玩家操控上限 | 全局共用，主要依靠科技研究与材料突破 | 各档具体材料、研究操作与节点 |
| 角色解锁 | 特定材料或其他条件决定具体角色是否开放 | 材料、条件、研究方式和是否可共享 |
| 装置承载 | 对角色与技能有支持范围和性能成长 | 门槛、升级方式、与个人操控上限的关系 |
| 角色与技能培养 | 每名角色与技能分别积累 | 成长曲线、熟练度和资源需求 |

这里的“全局”指同一玩家的角色库，不表示所有玩家共享操控或培养进度。个人培养独立的既有方向继续有效。

## 已确认：操控突破方式与四阶段骨架

个人操控上限主要通过科技研究与突破材料提升，实际使用积累主要用于角色与技能培养。用户要求控制重复劳动，讨论与方案均避免过度摊开。

| 阶段 | 已接受的进程方向 | 继续由候选方案补全 |
| --- | --- | --- |
| 铁阶段 | 基础装置与通用能力分支，辅助早期生存 | 入门配方、基础设施和分支内容 |
| 主世界进阶 | 开放Lv4档角色 | 研究节点、特性材料与具体角色 |
| 跨维度探索 | 结合下界、末地资源或挑战，开放Lv5 | 具体来源、阶段条件与解锁配方 |
| 终局 | 专门研究与突破条件，开放Lv6 | 终局目标、能力范围和装置强化 |

上述四段作为整体节奏已被用户接受，不等于已锁定某种矿物、首领、角色或硬性顺序。Lv6是本项目的游戏档位，不能据此推定原作角色设定。

## 当前工作：并行补全候选方案

用户授权对尚未完全确定的部分自由发挥，并要求几个子代理分别给出几版可行方案。三版完整替代方案已形成，分别侧重原版生存推进、探索研究与生活用途、操作连携。入口见[三版方案对比](proposals/2026-10-22/README.md)，其中具体新增规则仍为候选。

此授权用于设计补全与文档，不启动主题玩法代码实现。各版自行补全的槽位、数值、配方、材料、掉落、角色规格和物品规则均为提案。比较后可以整版选用，也可以按系统组合，不将三个版本并行开发。

角色与世界内容独立的边界继续有效。候选方案可设计角色部分必需的研究设施、材料与搜刮交互，基础体验不能依赖尚未开发的专属怪物、城市或另一内容模块。
## 已确认：材料获取兼顾定向与随机

玩家可以为目标主动寻找材料，也能在探索中意外发现解锁其他方向的材料。用户选择这两种体验并存，前期可选择范围应较广，部分角色或方向受特定稀有材料约束。

普通怪物可能低概率产出特性稀有材料，僵尸是用户举例，尚未排定来源与概率。用户进一步提出击杀后用Mod专属装置搜刮，并由装置等级影响可获取物品与概率，作为设计方向继续细化。

直接掉落与搜刮是额外机会还是替代关系、搜刮次数和对象、多人归属、费用、交互形式，以及搜刮工具是否与随身能力装置合一，均未确定。没有要求必须生成尸体模型或长期保留实体。

广泛初始选择与低档通用能力分支如何对应，仍待进一步讨论；不沿用助手先前提出的“少量入门角色”作为当前范围限制。

## 已确认：科技树与变身器获取主线

角色获取的重要主线是严格、有前置关系的科技发展，与原版 Minecraft 的矿物、世界探索或怪物推进顺序结合，并按材料获取难度安排发展，最终掌握某些角色的“变身器”。

“变身器”是当前使用的关键物品称呼，现定位为需要随身携带或装备的统一能力装置。装置配置已掌握的主副角色并控制使用，具体装备位置、是否改变外观、耐久和交易规则仍未确定。角色解锁与同一台装置的成长如何衔接，需要继续设计。

目前只确定方向，以下内容继续开放：

- 技术节点、研究形式、材料配方、加工设备与分支结构。
- 各阶段必须达到什么条件，是否允许替代路径，以及角色在科技进程中的分布。
- 原版矿物、区域、维度、怪物和首领分别承担什么作用；具体顺序尚未排定。
- 角色获取科技树与角色内部技能成长之间的关系。
- 角色部分所需制作内容与独立世界内容部分的归属，避免无意间形成基础进度硬依赖。

## 已确认：装置、基地配置与外出切换

- 使用一台统一装置管理主、副角色及相应技能；装置需要随身携带或装备，具体位置未定。
- 主副角色配置和技能配置只能在基地固定科技设施完成。随身装置提供使用与控制入口；控制面板的布局、查看功能和输入方式尚未确定。
- 外出通过快捷键切换当前操作的角色技能栏，主副关系保持不变。
- 切换拥有独立 CD，用于控制连续切换频率；两个角色的技能 CD 继续各自计时。
- 成功切换后，可以立即使用新角色当前可用的技能，不额外设置切换后的施放等待。技能本身的蓄力、动作等按各自设计，具体规则仍待技能讨论。
- 用户以杰斯的切换作为操作节奏参考。本稿只记录用户确认的上述机制，未复制或核对该角色在外部游戏中的完整机制或具体数值。

“只能在基地”通过什么设施条件实现、设施能否迁移或建造多个、是否存在临时配置点，尚未讨论；不预设基地坐标判定、供能或多方块要求。

## 已确认：切换后的残留与连携成长

前一个角色释放的持续效果在切换后仅保留有限时间。具体残留与连携窗口受连携方式、角色特性、技能特性及技能等级影响。

基础阶段就应保留可用的连携性质；成长可以扩展连携空间，同时保留操作时机与难度。不同技能是否完整维持、衰减、变为待触发状态，以及持续操控能力如何处理，尚未逐项确定。

## 已确认：个人培养与装置成长分开

角色等级与技能培养成果由玩家本人掌握，玩家之间独立。更换或重新制造装置后，个人培养进度保留；借用别人的装置仍按借用者本人的培养程度使用。

装置本身也有成长空间：承载条件可以影响强力角色或技能能否启用，装置性能可以影响主副切换 CD。具体承载门槛、基础性能、等级划分和与科技节点的关系尚未确定。

用户选择持续改进同一台装置，希望长期培养形成感情。装置的科技发展围绕持续改装展开。升级时词条、改装成果、名称与外观如何处理，尚未确认。

角色解锁、科技研究是否允许共享，物品借用、丢失、死亡和交易如何处理，需要另行讨论；个人培养独立不自动解决这些规则。

## 已确认方向：尽早接触角色能力

玩家应在原版生存较早阶段获得基础装置与第一种角色能力，以简单技能辅助早期生存，再经历长期成长曲线。

用户提出“可能有铁了就可以”，因此当前起步目标约为铁阶段，尚未锁定为拿到铁即自动解锁，也未确定铁是唯一材料或全部前置。第一角色、基础设施、制造配方、研究流程和耗时仍待选择。

## 延后讨论：抽卡；候选方向：装置随机词条

用户对抽卡和类似随机装备词条的长期追求提出兴趣，将其作为扩展长期可玩性的候选内容，并明确暂时搁置，先讨论关键设计。

抽卡不作为获得角色的主要方式。奖池、资源来源、概率、保底、重复角色收益等均未确认，也没有确定进入首版。讨论中出现的兑换、定向获取、特殊连携词条等做法均是助手提案。

2026-10-22 用户进一步提出装置可刷词条，例如冷却缩减和伤害提升，作为装置成长的候选方向。具体是否进入首版、获取与重铸方式、属性范围、上限、继承规则均未确定；技能 CD 缩减与切换 CD 缩减是否分别提供也未决定。

## 助手建议，尚未确认为规则

- 让副修保留跨体系搭配价值，同时以主修深度与完整能力范围体现本体优势。
- 按能力用途设计有效成长行为，例如战斗、侦测、探索或工具使用。
- 科技树采用共同基础与能力分支，在严格前置下保留同阶段选择。
- 让效果残留以原技能剩余持续时间为上限；区分效果持续时间与可参与连携的时间。
- 让装置基础承载等级通过科技与材料稳定提升，随机词条提供进一步优化。
- 升级尽量保留已有装置投入；词条继承、重铸和个性化表现后续讨论。
- 在已接受的四阶段骨架内合并研究、个人认证与装置改装的重复投入；各版提出具体做法供比较。

这些建议不能直接作为实现规格，也不包含任何已确认的槽位数值、材料名单或角色名单。
